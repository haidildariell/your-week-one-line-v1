One line, at most 100 characters, that sums up the entrant's week:
the five-minute bounty sprints, the one real win of the week, and the
punchline the week earned.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.

## Entry

> Two thousand bounty checks, one poem won four dollars - my wallet still thinks I'm unemployed.
